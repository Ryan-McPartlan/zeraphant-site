# Stimphony sound drop folders

Dump audio files into the dial folders below. They are picked up automatically — no code edits needed. Refresh `/passion/stimming` after adding files.

Supported: `.mp3` · `.wav` · `.ogg` · `.m4a` · `.webm`

```
public/passion/stimming/
  singing/                      ← Singing dial
  stimming/                     ← Stimming dial
  bits/                         ← Bits dial
  interview-with-a-vampire/     ← Interview with a vampire dial
  sprites/                      ← (characters, not audio)
```

Any filename is fine (`oath-01.mp3`, `My Clip.wav`, …). Each beat picks one file at random from that dial’s folder.
