# Good Boy leaderboard

Drop ranked voice notes here. They show up automatically on the Praise → Good Boy panel.

## Naming

```
{rank}-{Display-Name}.{ext}
```

Examples:

```
1-Ryan-McPartlan.mp3
2-Alex-Grieco.wav
3-Sam-Dahdel.mp3
```

- **rank** — leaderboard position (lower = better). Ties: alphabetical by filename.
- **Display-Name** — shown on the board; hyphens become spaces (`Ryan McPartlan`).

Supported: `.mp3` · `.wav` · `.ogg` · `.m4a` · `.webm`
